# Solutions

Answers for the lecture notebooks, the midterm review and the quizzes of *Software Programming* (IGS1931).

**Try it first.** Open the exercise version in the week's folder, write your own answer, and only then compare. You learn from working out *why* your answer was different, not from reading the solution.

- Solutions are posted **after** the class they belong to (lessons) or **after** the deadline (homework and quizzes).
- Each folder here has the same name as the week's folder, e.g. `solutions/week10-lists/` goes with `week10-lists/`.
- Every solution notebook links back to its exercise version at the top.

The list with Open-in-Colab links is in the [main README](../README.md#solutions).
